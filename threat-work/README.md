# Threat work

Hunting, research and detection engineering. The families answer "what
happened in this incident"; this folder answers "is this happening anywhere".

| Area | Purpose |
| --- | --- |
| [`hunts/`](hunts/) | Hypothesis-led searches across a population or time range. |
| [`research/`](research/) | Sourced analysis and candidate ideas for hunts or detections. |
| [`detections/`](detections/) | Alert logic intended for repeatable deployment and tuning. |

Work moves from research to hunt to detection only as an explicit, reviewed
step. Sitting in this folder is not a claim of production readiness.
